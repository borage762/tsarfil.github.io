ツァーフィル（Tsarfil）ルールブック
====================================

※この文書は、2026年11月10日までに確定したルールをまとめたもの。

1. ゲーム概要
------------

・ツァーフィルは、チェスに似た2人用のターン制ボードゲームである。
・盤面は11×11マス。
・各プレイヤーは駒を33個ずつ持ち、合計66個を使用する。
・先手はランダムに決定する。
・自分のターンには、次のいずれか1つを行う。
  - 盤上の駒を1つ動かす
  - 持ち駒を1つ盤に置く
  - パスをする
・どちらかのレックスが取られた瞬間にゲーム終了。レックスを取った側の勝利となる。
・500手に達しても決着がつかない場合は、ポイントで勝敗を決める（「8. ポイント」を参照）。
・引き分けはない。

2. 盤面の接続
--------------

・盤面の上下左右の端は、それぞれ反対側の端につながっている。
・盤面はトーラス状（ドーナツ状）に接続されている。
・右端を越えると左端に、左端を越えると右端に出る。
・上端・下端についても同様。
・斜め移動で端を越える場合も、横方向と縦方向はそれぞれ独立して接続する。
  例：右上方向に進んで右端を越えた場合、左端の同じ縦位置から、さらに上方向へ進む。
・端を越えた先のマスも、通常どおり移動距離に数える。
・同じマスを移動経路上で複数回通ることもできる。
・一周して元のマスに戻る移動も可能。ただし盤面は変わらないため、パスと同じ扱いとする。
・例外として、レックス・ライター・ヴェヒター・トルヴェヒターは上下の端を越えられない。
  - 斜め移動で上下の端を越えることもできない。
  - 左右の端は、他の駒と同じように越えられる。

3. 共通の移動・捕獲ルール
------------------------

・移動先に味方の駒がある場合、そのマスには移動できない。
・移動先に敵の駒がある場合、その敵駒を取って移動先に入る。
・駒は敵味方を問わず、種類に関係なく捕獲できる。
・レックスも、他の駒と同じように敵の駒を捕獲できる。
・長距離移動では、途中にある駒を飛び越えられない。
・長距離移動の経路上に敵駒がある場合、その駒のマスまで進んで捕獲し、そこで移動を終了する。
・捕獲した駒を通過したり、捕獲した後にその駒を飛び越えたりすることはできない。
・長距離移動の経路上に味方の駒がある場合、その先へは進めない。
・盤の端を越える経路でも、これらのルールは同じように適用される。
・移動経路が同じマスを複数回通る場合も、途中の駒を通過・飛び越しすることはできない。
・「敵駒がある場合のみ」と書かれた動きは、移動先に敵駒があるときだけ、その駒を取る形でしか行えない。
・「2マス先の敵駒を取る」動きでは、途中の1マスが空いていなければならない。
・レックスは、敵の駒に攻撃されているマスにも移動できる。チェスのキングのような「攻撃されているマスには入れない」という制限はない。

4. 各駒の移動方法
----------------

以下の「前方（上）」は各プレイヤーから見た方向を指す。白と黒の前方は互いに反対方向である。
【】内の記号は、初期配置の表で使う記号。価値は「8. ポイント」で使う。

【レックス（A）】価値：―
・縦、横、斜めの8方向に1マス移動できる。
・上下の端を越えられない。
・レックスが取られると、そのプレイヤーの敗北となる。

【リッター（B）】価値：4
・前方、前方斜め右、前方斜め左の3方向に、任意の距離を移動できる。
・進化するとベトリッターになる。

【ゾルダート（C）】価値：1
・前方に1マス移動できる。前方のマスに敵駒がいれば、その敵駒を取って進める。
・前方斜め右・前方斜め左には、移動先に敵駒がある場合のみ1マス移動して捕獲できる。
・進化するとトルダートになる。

【シュッツ（D）】価値：3
・左右方向に、任意の距離を移動できる。
・進化するとベトシュッツになる。

【ライター（E）】価値：9
・縦、横、斜めの8方向に、任意の距離を移動できる。
・上下の端を越えられない。

【レヒター（F）】価値：5
・上下左右の4方向に、任意の距離を移動できる。

【ヴィンケル（G）】価値：4
・斜め4方向に、任意の距離を移動できる。

【ヴェヒター（H）】価値：2
・上下左右の4方向について、移動先に敵駒がある場合のみ、最大2マス移動して捕獲できる。
・上下の端を越えられない。
・進化するとトルヴェヒターになる。

【フェスト（J）】価値：2
・前方、前方斜め右、前方斜め左、後方、後方斜め右、後方斜め左の6方向に1マス移動できる。
・左右への直線移動はできない。

【ビーゲン（K）】価値：2
・左右および斜め4方向の計6方向に1マス移動できる。
・前方・後方への直線移動はできない。

【ライバ（O）】価値：3
・上下方向に、任意の距離を移動できる。
・進化するとリライバになる。

5. 進化した駒の移動方法
----------------------

以下の駒は初期配置には含まれず、進化によってのみ現れる。

【トルヴェヒター】価値：3（ヴェヒターが進化）
・上下左右の4方向について、移動先に敵駒がある場合のみ、最大2マス移動して捕獲できる。
・斜め4方向には、移動先に敵駒がある場合のみ1マス移動して捕獲できる。
・上下の端を越えられない。

【トルダート】価値：2（ゾルダートが進化）
・前方に最大2マス移動できる。途中の駒は飛び越えられない。
・前方斜め右・前方斜め左・右・左には、移動先に敵駒がある場合のみ1マス移動して捕獲できる。

【ベトシュッツ】価値：5（シュッツが進化）
・左右方向に、任意の距離を移動できる。
・上下方向に1マス移動できる。
・上下方向の2マス先に敵駒がある場合、移動して捕獲できる。

【リライバ】価値：5（ライバが進化）
・上下方向に、任意の距離を移動できる。
・左右方向に1マス移動できる。
・左右方向の2マス先に敵駒がある場合、移動して捕獲できる。

【ベトリッター】価値：6（リッターが進化）
・前方、前方斜め右、前方斜め左の3方向に、任意の距離を移動できる。
・左右方向に1マス移動できる。

6. 進化
--------

・駒は1個ごとに、その駒が取った敵駒の価値の合計をためていく。
・合計が5以上になった時点で、その駒は自動的に進化する。手番は使わない。
・進化できるのは次の5種類のみ。
  - ゾルダート → トルダート
  - シュッツ → ベトシュッツ
  - ライバ → リライバ
  - リッター → ベトリッター
  - ヴェヒター → トルヴェヒター
・進化した駒は、それ以上進化しない。

7. 持ち駒
----------

・駒を取ると、取った駒は盤から取り除かれる。
・取った駒は、2分の1の確率で取った側の持ち駒になる。持ち駒にならなかった駒はゲームから除かれる。
・進化した駒を取った場合、進化前の駒として持ち駒になる。
・自分の手番に、持ち駒を1つ盤に置くことができる。置くことで1手となる。
・持ち駒は、空いているマスのうち、敵陣以外の場所に置ける。
  - 敵陣とは、相手の初期配置の3段を指す（白にとっては8〜10段目、黒にとっては2〜4段目）。
・盤に置いた駒は自分の駒として扱い、取った駒の価値の合計は0から数え直す。

8. ポイント
------------

・双方にポイントがあり、対局開始時はどちらも0。
・駒を取ると、取った側に取った駒の価値の分だけポイントが加算される。
・駒を取られると、取られた側から同じ値が減算される。
・レックスの捕獲はポイントの対象外（その時点で勝敗が決まる）。
・500手に達しても決着がつかない場合、ポイントの多い側の勝利とする。
  - 手数はパスも含めて数える。
  - 同点の場合は、ポイントに差がつくか、レックスが取られるまで対局を続ける。

9. 駒の内訳
----------

各プレイヤーの駒数は以下のとおり。合計33個。

・レックス：1個
・リッター：2個
・ゾルダート：10個
・シュッツ：2個
・ライター：2個
・レヒター：2個
・ヴィンケル：2個
・ヴェヒター：4個
・フェスト：3個
・ビーゲン：3個
・ライバ：2個

合計：33個（各プレイヤー）

10. 初期配置
------------

・白と黒の初期配置は、盤の中心を基準に180度回転させた点対称とする。
・各マスに置ける駒は最大1個。
・白は2〜4段目、黒は8〜10段目に駒を置く。1・5・6・7・11段目は空きマスとする。
・白の配置は以下のとおり（左から a〜k 列。記号は「4. 各駒の移動方法」を参照）。

  4段目（最前列）：C C C C C J C C C C C
  3段目　　　　　：G O F H J A J H F O G
  2段目（最後列）：D K B E H K H E B K D

・黒の配置は、白の配置を180度回転させたもの（10段目が最後列、8段目が最前列）。
  各段は左右対称のため、黒の各段も白と同じ並びになる。

11. ルールの要点
--------------

・先手はランダム。
・各ターンは駒を1つ動かすか、持ち駒を1つ置くか、パスできる。
・味方の駒があるマスには入れない。
・敵駒は種類を問わず捕獲できる。
・長距離移動で駒を飛び越すことはできない。
・盤の端は反対側につながっており、移動距離は通常どおり数える。
  ただし、レックス・ライター・ヴェヒター・トルヴェヒターは上下の端を越えられない。
・取った駒は2分の1の確率で持ち駒になる。
・取った駒の価値の合計が5以上になった駒は自動で進化する。
・レックスが取られた瞬間にゲーム終了。
・500手で決着しなければポイントで判定する。
・引き分けはない。
